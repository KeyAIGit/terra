# TERRA → Unreal Engine 5: как собрать уровень одним скриптом

Эта папка — готовый пакет: три сцены твоего мира (`capital/`, `bronze/`,
`neolithic/`), общий скрипт `import_terra.py` и эта инструкция. Всё, что ниже,
рассчитано на человека, который открыл Unreal Engine первый раз в жизни.

Понадобится: Unreal Engine **5.4 или новее** (ставится через Epic Games
Launcher, вкладка Unreal Engine → Library → «+»), ~30 ГБ места, полчаса.

---

## Шаг 1. Создать пустой проект

1. Запусти Unreal Engine из Epic Games Launcher.
2. В окне выбора проекта слева выбери **Games**, шаблон **Blank**.
3. Справа: **Blueprint**, **Starter Content — ВЫКЛЮЧИТЬ** (галочку снять),
   Quality — Maximum, Raytracing — можно выключить.
4. Задай имя, например `Terra`, и нажми **Create**.

Откроется редактор с пустой сценой — это нормально.

## Шаг 2. Включить Python

1. В меню сверху: **Edit → Plugins**.
2. В поиске набери `Python`, поставь галочку на **Python Editor Script
   Plugin** (может уже стоять).
3. Нажми **Restart Now** — редактор перезапустится.

## Шаг 3. Скопировать пакет в папку проекта

Скопируй ВСЮ папку `export_ue` внутрь папки проекта, рядом с файлом
`Terra.uproject`. Должно получиться так:

```
Документы/Unreal Projects/Terra/
├── Terra.uproject
├── Content/ …
└── export_ue/
    ├── import_terra.py
    ├── README_UE.md
    ├── capital/  bronze/  neolithic/
```

Если папка лежит именно так — скрипт найдёт её сам («auto»).

## Шаг 4. Выбрать сцену

Открой `export_ue/import_terra.py` любым блокнотом. В самом верху:

```python
SCENE = "capital"      # ← поменяй на "bronze" или "neolithic" при желании
SCENE_DIR = "auto"     # ← можно не трогать, если сделал шаг 3
```

Если положил папку в другое место — впиши в `SCENE_DIR` полный путь к папке
сцены, например `r"D:/terra/export_ue/capital"` (буква `r` перед кавычками
обязательна).

## Шаг 5. Запустить скрипт

1. В редакторе: **Window → Output Log** (внизу появится журнал).
2. Внизу журнала есть строка ввода, слева от неё выпадашка `Cmd` —
   переключи её на **Python**.
3. Вставь одной строкой (подставь СВОЙ путь) и нажми Enter:

```python
exec(open(r"C:/Users/ТЫ/Documents/Unreal Projects/Terra/export_ue/import_terra.py", encoding="utf-8").read())
```

Скрипт 1–3 минуты будет импортировать меши и расставлять акторы; в журнале
идут строки `[terra] …`, в конце — «СВОДКА».

## Что должно получиться

- Новый уровень `Content/Terra/Maps/L_capital` (открыт автоматически):
  холмистая долина 1,2 × 1,2 км с запечённой «живой» текстурой (тропы, поля,
  песок у воды), вокруг — рельеф до горизонта, река/море, если есть в сцене.
- Несколько сотен зданий-блокаутов по данным симуляции: дома, храм или
  зиккурат, стены, башни, ворота, рынок, поля, загоны, лодки, причал.
- Жители: фигурки на местах спавна, над головой имя и роль (это реальные
  люди из книги мира — их карточки лежат в `people.json`).
- Солнце по широте сцены, небо, лёгкий туман, мягкий тонмаппинг.
- `PlayerStart_TERRA` на главной площади: жми **Play** (зелёный треугольник)
  и ходи по городу (WASD + мышь).

## Если что-то не так

| Симптом | Что делать |
|---|---|
| `Папка сцены не найдена` | Шаг 3 сделан не так, либо впиши `SCENE_DIR` вручную (шаг 4). |
| В выпадашке нет «Python» | Плагин не включён или редактор не перезапущен (шаг 2). |
| `SyntaxError` при вставке | Вставь команду ОДНОЙ строкой, путь в `r"…"`. |
| Ландшафт лежит «на боку» | Скрипт обычно чинит это сам (строка «компенсирую креном»). Если нет — выдели `Terrain_TERRA` и поставь Rotation X = −90. |
| Всё чёрное | Подожди 10–20 с (свет строится), покрути мышью. Проверь, что в сводке нет ERR у DirectionalLight/SkyLight. |
| Здания без цвета (шахматка) | Не создались материалы — не страшно, это блокаут; см. «дальше к фотореализму». |
| Скрипт написал ERR | Скопируй ВЕСЬ Output Log (Ctrl+A, Ctrl+C в журнале) в файл и пришли Фейблу в чат — по логу всё чинится. |
| Хочу другую сцену | Поменяй `SCENE` (шаг 4) и запусти скрипт ещё раз — соберётся отдельный уровень. |

## Что лежит в папке сцены (если захочешь руками)

- `terrain.obj` + `terrain_color.png` — ландшафт-меш (см, Z вверх) и его
  текстура; `terrain_far.obj` — кольцо до горизонта; `water.obj` — вода.
- `masks/heightmap.png` — высоты PNG16 для НАСТОЯЩЕГО UE-Landscape, если
  когда-нибудь захочешь: Landscape Mode → Import from File. Числа для полей
  импорта лежат в `meta.json` → `heightmap`: масштаб X/Y =
  `landscape_scale_xy`, Z = `landscape_scale_z`, а сам Landscape-актор
  поставить по Z на `landscape_z_location_cm`. Смысл: 0 в PNG = `min_cm`,
  65535 = `max_cm`; верхняя строка картинки — север (−Y).
- `masks/grass|dirt|rock|sand.png` — весовые карты материалов (готовые
  layer-маски под Landscape-материал или Runtime Virtual Texture).
- `buildings.json` / `people.json` / `meta.json` — манифесты: типы, позиции
  в см, повороты, размеры, карточки жителей, маршруты, широта для солнца.
- `proxy_meshes/` — блокаут-примитивы типов зданий (слоты материалов
  walls / roof / trim — легко перекрасить или заменить меши).

## Дальше — к фотореализму

Блокаут — это каркас. Красота накладывается поверх, не трогая расстановку:

1. **Fab / Quixel Megascans** (бесплатно для UE): в редакторе **Window →
   Fab**, ищи `grass`, `rock cliff`, `dirt road`, `mud brick`, `thatch` —
   отсканированные материалы и камни. Перетащи материал на ландшафт или
   собери Landscape-материал, подключив мои маски grass/dirt/rock/sand.
2. **Замена блокаутов**: в Fab полно бесплатных наборов «ancient village»,
   «medieval house». Скачал ассет → правой кнопкой по моему прокси в World
   Outliner → Replace Selected Actors with… — позиции и повороты сохранятся.
3. **MetaHuman** (Window → Quixel Bridge → MetaHumans): фотореалистичные
   люди; имена и роли бери из `people.json`.
4. Свет: у солнца включи Atmosphere Sun Light (уже включён скриптом),
   добавь Volumetric Cloud (Place Actors → Visual Effects), в
   PostProcess_TERRA поиграй Exposure Compensation.
5. Вода: плагин **Water** (Edit → Plugins → Water) вместо моей плоскости.

Хорошей прогулки по своему миру.
